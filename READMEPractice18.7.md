Практическая работа по основам Python

Электронный дневник школьного класса
Итоговый проект: консольное приложение для хранения и обработки оценок учеников по предметам. Работа с вложенными словарями и списками, методы массивов и словарей.

Функциональность
Хранение оценок каждого ученика по разным предметам.

Полное управление оценками: добавление, редактирование, удаление.

Управление учениками: добавление, переименование, удаление.

Управление предметами: добавление, переименование, удаление.

Аналитика: средние баллы по ученикам, предметам и классу в целом.

Структура данных
python
students_marks = {
    "Имя ученика": {
        "Предмет": [оценки]
    }
}
Пример данных
python
students = ["Аполлон", "Ярослав", "Александра", "Дарья", "Ангелина"]
classes = ["Математика", "Русский язык", "Информатика"]
Оценки генерируются случайно от 1 до 5 через random.randint(1, 5).

Запуск
bash
python main.py
Требуется Python 3.7+. Внешних зависимостей нет (только стандартный random).

Меню команд
text
Список команд:
    1.  Добавить оценки ученика по предмету
    2.  Вывести средний балл по всем предметам по каждому ученику
    3.  Вывести все оценки по всем ученикам
    4.  Добавить имя нового ученика
    5.  Редактировать имя ученика
    6.  Удалить имя ученика
    7.  Добавить новый предмет
    8.  Редактировать название предмета
    9.  Удалить предмет
    10. Редактировать оценку ученика по предмету
    11. Удалить оценку ученика по предмету
    12. Вывести информацию по всем оценкам по ученику
    13. Вывести средний балл по каждому предмету по ученику
    14. Средний балл класса по каждому предмету
    15. Выход из программы
